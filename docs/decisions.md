# 자율 실행 중 결정

사용자의 “더는 묻지 말고 끝까지” 지시에 따라 추가 승인 질문 없이 작업했다. 초기 구현은 코드와 산출물을 기존 `/workspace/langswitcher` 작업 공간에 보존했다. 이후 사용자가 main 병합 및 push를 명시적으로 요청했으므로, 검증을 거쳐 Git에 반영한다. 공개 호스팅은 수행하지 않았다.

1. 설계·계획 승인 질문을 반복하지 않고 직접 실행했다. 이미 승인한 웹/규칙/데스크톱 범위를 적용했다. 잘못 해석했다면 기능 범위 수정이 필요하다.
2. 이미 격리된 클라우드의 `work` 체크아웃을 사용하고 추가 worktree를 만들지 않았다. 환경 계약과 사용자 작업 보존을 따른다. 잘못 해석했다면 별도 분리 작업이 필요하다.
3. 리뷰어의 Minor인 초대/촛대 오변환도 실제 의미를 바꾸는 결함이므로 Important로 재분류해 같은 수정 단계에서 처리했다. 우선순위 판단이 달랐다면 작은 규칙 수정이 앞당겨진 비용만 발생한다. 미룬 리뷰 항목은 없다.
4. Windows 네이티브 빌드는 기본 NSIS 절차를 유지했다. Linux의 Wine beta 로더 오류는 해당 실행에서 만든 최신 중간 파일을 stock `UninstallerReader`로 읽는 지원 custom-script 경로로 해결했다. 검증을 끄거나 종속성 코드를 수정하지 않았다. 이 결정의 확인 비용은 Windows 실제 설치/제거 검증이며 현재 미검증이라고 명시했다.

정확도 수치를 꾸며내지 않았다. 독립 코퍼스와 원문 대조가 없는 상태에서 90% 달성이나 완벽한 규범 적용을 주장하지 않는다. 구체적인 한계·검증 결과는 `verification.md`와 `linguistic-model.md`에 기록했다.
